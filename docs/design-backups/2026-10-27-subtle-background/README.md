# 메인 배경 비교용 원본

색 번짐 강도를 높이기 직전의 메인 화면 소스를 `page_main.dart.before.txt`에 보관했습니다.
이 파일은 비교 자료이며 앱 빌드에 포함되지 않습니다.

되돌릴 때는 이후 다른 수정을 잃지 않도록 전체 파일을 덮어쓰지 말고,
`lib/page_main.dart`의 목록 영역 RadialGradient 두 개만 아래 설정으로 복구합니다.

| 설정 | 기존 옅은 배경 | 비교용 진한 배경 |
|---|---|---|
| 살구 중심 | Alignment(-0.95, -0.85) | 동일 |
| 살구 radius | 1.15 | 1.5 |
| 살구 colors | 0x14E69B70 → 0x00E69B70 | 0x38E69B70 → 0x00E69B70 |
| 로즈 중심 | Alignment(0.95, 0.85) | 동일 |
| 로즈 radius | 1.1 | 1.45 |
| 로즈 colors | 0x12A64F60 → 0x00A64F60 | 0x2EA64F60 → 0x00A64F60 |

기존 최대 불투명도는 살구 7.8%, 로즈 7.1%이며 비교용은 각각 22.0%, 18.0%입니다.
